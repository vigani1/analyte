# Code of conduct

Analyte adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in every project space: issues, pull
requests, reviews, discussions and any other place where you represent the
project. Translations are listed on the
[Contributor Covenant site](https://www.contributor-covenant.org/translations/).

In short: be respectful and welcoming, give and accept feedback kindly, and
keep personal attacks, harassment and other people's private information out
of the project.

## Reporting

Report unacceptable behaviour to the maintainer privately through GitHub: use
the repository's private reporting form
([Report a vulnerability](https://github.com/vigani1/analyte/security/advisories/new))
and start the title with "Conduct", or contact the maintainer through their
GitHub profile. Do not post the report publicly.

Every report is reviewed promptly and fairly, and the reporter's privacy is
respected. The maintainer decides on the consequences, following the
Contributor Covenant's enforcement guidelines.
