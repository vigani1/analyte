Accepted differences from the standard

This model does a few things its own way. Analyte handles them for you:

  • Sends the sample ID in a different place in the message. Analyte reads it from there.
  • Sends “no result” as an empty value instead of a code. Analyte treats it as “not measured”.
  • Doesn’t confirm orders. Analyte marks them “sent” and waits for results.
