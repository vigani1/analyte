# LAW versions

The implemented profile is IHE PaLM Technical Framework **Rev 11.0**,
LAW Analyzer Manager on HL7 **2.5.1**, using the selected LAB-27, LAB-28
and LAB-29 transactions. Evidence remains documented, including the recorded
message-validation and incomplete conversation evidence described in the checklist.

| Profile | Difference that matters | Source |
| --- | --- | --- |
| LAW Rev 11.0 | Adds actor, transaction and field constraints over base HL7 | Existing section references in [checklist](checklist.md) |
| Base HL7 2.5.1 | Generic syntax alone is insufficient to establish LAW conformance | [HL7 versions](../hl7/versions.md) |

No other LAW revision is qualified. The profile is selected explicitly;
there is no automatic negotiation of Technical Framework revisions. Another
revision needs a reviewed difference table and tests before support is claimed.
