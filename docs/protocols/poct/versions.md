# POCT versions

Analyte targets **CLSI POCT01-A2 (2006)**, commonly called POCT1-A, as
DML Observation Reviewer over TCP. Evidence remains documented and the Basic
Profile conformance gate remains open.

| Choice | Difference that matters | Source |
| --- | --- | --- |
| DML Basic Profile | Selected observation-review conversation; incomplete evidence is explicit | Existing section references in [checklist](checklist.md) |
| Access Point and ORI | Separate interfaces, not implied by DML or the HTTPS app contract | Scope and conditional rows in [checklist](checklist.md) |

No other edition is qualified. Unsupported version declarations are rejected;
there is no fallback to another edition or to an assumed compatible XML schema.
