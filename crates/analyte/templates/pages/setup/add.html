The machine

Adds a machine that is not set up yet. Analyte checks the settings, keeps a dated copy of the old ones and writes the new ones; if anything fails, the old settings are put back. Then the setup steps follow: its model, its connection, a test and the save.

Letters, digits, - and _. It also names the machine’s settings file (name.site.toml) and cannot change later: stored results are kept under it.

Reusing a name

Analyte keeps results, items to review and history by machine name. A machine added under the name of one removed earlier joins that stored history. Use an earlier name only for the same analyzer; give a different analyzer a new name, so its results are never matched with the old one’s.

Needed only when the name has stored history.
